# Kutipan — bukti yang dapat diperiksa

Setiap sumber yang disitasi di naskah WAJIB punya bukti di sini:

- `buku/` — foto/scan halaman yang dikutip (secukupnya, fair use) + file catatan `.md`
  berisi: halaman persis, kata-kata persis kutipan, konteks.
- `artikel_jurnal/` — sama, untuk artikel.
- `sumber_primer/` — sama, untuk sumber primer (mis. terjemahan karya al-Farabi).
- `metadata/` — hasil verifikasi Crossref / katalog perpustakaan per sumber (simpan JSON/catatan).

Format nama berkas: `<kunci-bibtex>_<halaman>.<ext>`, mis. `gutas1998_h45.md`.

Tanpa bukti di direktori ini, sitasi di naskah dianggap BELUM terverifikasi.
