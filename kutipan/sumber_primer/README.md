# Sumber Primer — petunjuk akses legal

Direktori ini TIDAK menyimpan salinan bajakan karya al-Farabi.

Yang tersedia legal dan terverifikasi:

- Terjemahan Inggris tiga karya politik-filsafat Farabi via Mahdi 1969 (S09):
  lihat `../buku/S09_mahdi1969_catatan.md`. Teks-penuh belum diakses legal.
- Teks Arab _Ihsa al-'Ulum_ (ed. Bumelham) dan karya logika lain terindeks di
  direktori MuslimPhilosophy.com (http://www.muslimphilosophy.com/farabi —
  HTTP 200, diverifikasi sebagai direktori karya, BUKAN otoritas sitasi).
  Setiap file PDF Arab yang dipakai wajib diverifikasi terpisah
  (edisi, editor, kelengkapan) sebelum disitasi.
- Kutipan isi karya logika Farabi dalam naskah ini dirujuk via kajian
  teks-penuh SEP S01 (bagian 5–7) dengan referensi presisi
  (mis. _Ihsa al-'Ulum_ 59.9–11, _Syllogism_ 27.6, _Expressions_ 100.3–5),
  bukan klaim baca manuskrip langsung. Lihat `log/catatan_verifikasi.md`.

Aturan: jangan menambahkan file ke sini tanpa mencatat edisi, editor,
sumber unduhan resmi, dan lisensi di file catatan pendamping.
